# Quality Review: Q1 2025 Headlamp Returns

## Findings
Headlamp return rate rose to 4.1% in Q1, driven by the ZX-481. Root cause analysis attributed 62% of returns to the firmware 2.1 battery gauge bug rather than hardware defects. Actual cell failures were 0.3%.

## Actions
Support scripts updated to check firmware version before opening an RMA. Warehouse inspection now includes a capacity test at 0.5 C discharge.

## Outlook
Return rate expected to fall below 2% once firmware 2.3 adoption exceeds 80%.
